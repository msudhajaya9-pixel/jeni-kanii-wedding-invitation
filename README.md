# John Jenith & Nagakanni — Wedding Invitation

A responsive, static wedding invitation website made with the supplied original photos.

## Preview locally
Open `index.html` in a browser.

## Deploy to Vercel
1. Create a GitHub repository and upload the contents of this folder (keep `index.html`, `style.css`, `script.js`, and `assets/` at the repository root).
2. Sign in to Vercel with GitHub and choose **Add New → Project**.
3. Import this repository. Framework preset: **Other**. Build command: leave empty. Output directory: `.`.
4. Click **Deploy**. Vercel will provide a public `*.vercel.app` URL you can share on WhatsApp.
5. Optional: connect a custom domain in the project's Settings → Domains.

## Details to update before publishing
- In `index.html`, replace `Bride's Home` and `Groom's Home` with the exact venue names/addresses.
- Add a Google Maps link for each venue if you want map buttons.
- The uploaded photos include 7 gallery pictures (in addition to the separate bride, groom and hands photos). Add 9 more gallery photos if you want a full 16-photo gallery.
- The exact proposal time was not displayed because “morning 12.00” could mean midnight or noon.

No face retouching, face replacement, or AI alteration is applied to the supplied photos.
